# CapturaClipA2

<img src="docs/icon_001.png" width="64" alt="CapturaClipA2 のアイコン">

画面の一部を切り取って、最前面に貼り付けておくための Windows 用ツールです。

別のウィンドウに切り替えると見えなくなる情報を、画面の隅に置いたまま作業できます。切り取った後は、線を引く・文字を入れる・隠したい所をぼかす、といった加工ができます。

## 入手

[Releases](https://github.com/a2d4f3s1/CapturaClipA2/releases/latest) から zip を落として、好きな場所に展開してください。インストールは不要です。

## 動作環境

Windows 10 / 11（64bit）。追加のランタイムは不要です。実行ファイル 1 つで動きます。

### はじめて起動するとき

- 「WindowsによってPCが保護されました」→「詳細情報」→「実行」（コード署名をしていないためです）
- ウイルス対策ソフトが反応することがあります。スポイト中だけマウス入力を横取りする仕組みを使うためで、終了すれば外れます

## 使い方

起動するとカーソルが十字に変わり、画面が固定されます。

| 操作 | 動作 |
|---|---|
| ドラッグ | 範囲を選んでキャプチャ |
| クリック | カーソル下のウィンドウ全体をキャプチャ |
| Ctrl + クリック | 同上。タイトルバーと枠を除いた中身だけ |
| 右クリック / Esc | キャンセルして終了 |

切り取ったウィンドウは、既定ではタイトルバーがなく、常に最前面です。**右クリックでメニュー**が開き、すべての機能に辿れます。

![右クリックメニュー](docs/CCA2_RMB_Menu_01_main.png)

### ツール

| キー | ツール | 左ドラッグ |
|---|---|---|
| V | ビュー | 画像をスクロール |
| B | ペン | 描画 |
| E | 消しゴム | なぞった線を消す |
| T | テキスト | （クリックで入力開始） |
| W | 範囲選択 | 矩形を選ぶ |
| L | 投げ縄 | 手で囲って選ぶ |
| Ctrl + W | オブジェクト選択 | 置いたものを矩形で囲って選ぶ |
| Ctrl + L | オブジェクト投げ縄 | 置いたものを手で囲って選ぶ |
| Shift + I | スポイト | 画面から色を拾う |

<img src="docs/CCA2_RMB_Menu_02_tool.png" width="200" alt="ツールのサブメニュー">

### ウィンドウの操作

| 操作 | 動作 |
|---|---|
| 中ドラッグ | ウィンドウを移動 |
| 四辺・四隅をドラッグ | ウィンドウをリサイズ |
| Space を押しながら左ドラッグ | 一時的にスクロール |
| Ctrl + ホイール | ズーム（Shift 併用で微調整） |
| ホイール | 不透明度 |
| 1 〜 5 | 倍率を 100 / 200 / 300 / 400 / 500% に |
| カーソルキー | スクロール |
| F | ウィンドウを画像サイズに合わせる |
| X | しばらく隠す |

### ファイル

| 操作 | 動作 |
|---|---|
| Ctrl + S | 名前を付けて保存 |
| Ctrl + C | クリップボードにコピー |
| Ctrl + O | 画像ファイルを開く |
| Ctrl + V | クリップボードの画像を貼り付け |
| Ctrl + Z / Ctrl + Y | 元に戻す / やり直し（回数制限なし） |

- 開く・貼り付け・ドロップは、今の画像を置き換えます
- 保存とコピーには、描いた線・文字・ぼかしが反映されます
- 画像ファイルを引数に渡して起動すると、キャプチャせずにその画像を開きます

## 設定

右クリックメニューの「設定...」から開きます。タブは 全般 / 描画 / 色 / 文字 / 保存 / ウィンドウ / 操作の割り当て です。

<img src="docs/CCA2_Setting_01_general.png" width="420" alt="設定の全般タブ">

キーとマウスの割り当ては「操作の割り当て」タブで変えられます。設定は実行ファイルの隣の `CapturaClipA2.ini` に保存されます。

## 詳しい説明

[docs/manual.md](docs/manual.md) にあります。

- 描く（蛍光マーカー・直線・矢印・ペンタブレット・色）

## 開発

### ビルド

- Visual Studio 2022（「C++ によるデスクトップ開発」）または Build Tools 2022
- CMake 3.20 以上（Visual Studio 同梱のもので構いません）

```
cmake -S . -B build
cmake --build build --config Release
```

Visual Studio 同梱の CMake は既定では PATH に入りません。**「Developer Command Prompt for VS 2022」から実行**するか、CMake を別途入れてください。

`build/Release/CapturaClipA2.exe` ができます。C++20、CRT は静的リンクなので、追加のランタイムなしで動きます。

**アプリが起動しているとリンクに失敗します**（`LNK1104`）。閉じてからビルドしてください。

### コマンドライン引数

**いずれも開発用です。** ふだん使うときに指定する必要はありません。

| 引数 | 内容 |
|---|---|
| （ファイルパス） | キャプチャせずにその画像を開きます（画面のスナップショットを撮りません） |
| `--timing` | 1 フレームの内訳を、実行ファイルの隣の `timing.log` に書き出します |
| `--prepare=<ミリ秒>` | 画面を読むまでの待ち時間を上書きします |
| `--wait=<プロセス ID>` | そのプロセスが終わるまで待ってから画面を読みます |

`--prepare` と `--wait` は「撮り直す」が自分を起動し直すときに使うものです。
