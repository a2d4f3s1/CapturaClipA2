# CapturaClipA2 の詳しい説明

基本の操作は [README](../README.md) にあります。ここには各機能の細かい振る舞いと、設定の全項目を置いています。

## 描く

| 操作 | 動作 |
|---|---|
| Shift + ドラッグ（ペン） | 直線 |
| `[` `]` | ブラシ・消しゴムのサイズ |
| R（描いている間・引き終えた直後） | 矢印の頭を付ける |
| Ctrl + ↑ ↓（置いた直後） | 矢印の頭の向きを微調整 |
| Shift + 1 〜 8 | クイックカラー |
| A | アンチエイリアスの切り替え |
| H | 蛍光マーカーの切り替え |
| I | カラーパレット |
| Shift + I | スポイト |
| Alt + ドラッグ | 押している間だけスポイト |

- ペンと消しゴムでは、カーソルに実サイズの円が出ます。**オレンジ**＝アンチエイリアスなし、**白**＝あり
- 太さ・蛍光マーカー・アンチエイリアス・筆圧は、メニューの「線」からも切り替えられます

<img src="CCA2_RMB_Menu_04_line.png" width="200" alt="線のサブメニュー">

### 蛍光マーカー

- `H` でペンが蛍光マーカーになります。太さと色はペンと共通です
- 半透明なので下の文字が読めます
- 1 ストロークの中では、線が自分自身と交差してもそこだけ濃くなりません

### 直線

`Shift` を押しながら引くと直線になります。押し始めた時点で決まるので、途中で離しても直線のままです。

| 操作 | 動作 |
|---|---|
| Alt（引いている間） | 角度を一定ずつに揃える。既定は 15 度 |
| Shift をもう一度押す（引いている間） | そこで折り曲げて、続けて引く |
| `[` `]`（引いている間） | **終点**の太さ |
| Ctrl + `[` `]`（引いている間） | **始点**の太さ |

- **Alt は引き始めてから押してください。** `Shift + Alt` の状態でクリックするとスポイトになります
- `Shift` を押し直すたびに折れ目ができます。太さは前後でつながります
- 揃える角度は設定の「描く」タブ。`0` で揃えません
- 直線の太さは筆圧ではなくブラシサイズで決まります
- 引いている間、タスクバーに `Line 4 → 12px` と両端の太さが出ます
- 両端に差をつけると、入り抜きのある線になります

### 矢印

線を引いている最中に `R` を押すと、そこに矢印の頭が付きます。向きは線が進んでいた向きで、1 本に何個でも置けます。

- **引き終えた直後でも `R` は効きます。** マウスを動かす以外のことをすると受け付けなくなります
- `Ctrl + ↑` `Ctrl + ↓` で置いた直後の向きを微調整（既定 5 度）。回せる間はタイトルに出ます
- 直線を狙い直すと、頭は端に付いてきます。傾けた分も残ります
- 大きさはその場所の線の太さで決まります。押す直前に `[` `]` で変えれば頭だけ変わります

| 設定（描画タブ） | 意味 | 既定 |
|---|---|---|
| 矢印の大きさ | 線の太さの何倍の幅にするか | 3 |
| 矢印の長さ | 幅の何倍の長さにするか | 1.2 |
| 矢印の角の丸み | 幅の何倍の半径で角を落とすか | 0.15 |
| 矢印の向きの刻み | `Ctrl + ↑` `Ctrl + ↓` 1 回で回る角度 | 5 度 |

いずれも頭の幅が基準です。線の太さを変えると全部が比例して変わります。

### ペンタブレット

- 筆圧に対応しています（Windows Ink 経由。ペンタブ側の設定で有効にしてください）
- **ペンを裏返すと消しゴム**になり、離すと元のツールに戻ります
- 筆圧の ON / OFF はメニューの「線」から

### 色

<img src="CCA2_RMB_Menu_03_color.png" width="240" alt="カラーパレット">

`I` でカラーパレットが開きます。彩度・明度の面と色相バー、その下にクイックカラーと履歴が並びます。

- 履歴の左端が今の色で、作業中はリアルタイムに変わります
- パレット外をクリックで確定、`Esc` で取り消し

`Shift + I` はスポイトです。拡大窓が出て、拾えるピクセルに枠と色の値が付きます。

- **画面のどこからでも拾えます**
- 押したまま動かすと拾う色が付いてきます。決まるのは離した位置の色です
- スポイト中、クリックは下のアプリに届きません。右クリックでやめられます
- `Alt + ドラッグ` も同じスポイトです。押している間だけで、離すと元のツールへ戻ります
- Alt は押してからクリックしてください。描き始めたあとの Alt は、直線の角度を揃える操作です

## 文字

`T` でテキストツールに切り替え、クリックした位置から入力します。日本語入力（IME）に対応しています。

| 操作 | 動作 |
|---|---|
| クリック | その位置に入力を開始 |
| Enter | 改行 |
| 入力欄の外をクリック / Ctrl + Enter / Esc | 確定 |
| 既存のテキストをクリック | **再編集**（内容が入力欄に戻ります） |
| 既存のテキストをドラッグ | 位置を動かす |
| 入力中に右クリック | 書式のメニュー |
| Ctrl + B / I / U | 太字 / 斜体 / 下線 |
| Ctrl + `[` `]`（入力中） | 文字サイズ |
| `[` `]`（テキストを指しているとき） | そのテキスト全体の大きさ |

<img src="CCA2_RMB_Menu_05_text.png" width="200" alt="文字のサブメニュー">

- 入力欄は確定後と同じフォント・サイズ・色で表示されます
- 選んだ範囲だけ、太字・斜体・下線・打ち消し線・色・サイズ・フォントを変えられます
- 何も選ばずに指定すると、そこから先に打つ文字に適用されます
- 再編集しても作成時の書式を保ちます
- **縁取りと影は、テキストを指した状態で右クリック →「文字」から切り替えます。**その場で反映され、
  取り消し（Ctrl + Z）で戻せます。どのテキストも指していないときは、次に打つテキストに効きます
- 同じ「文字」メニューから、**大きさ・縁の太さ・影の長さ・影の濃さ**を数字で打ち込めます。
  押した位置に小さな入力欄が出るので、数字を入れて Enter です（Esc で取り消し）
- **縁の太さと影の長さは、文字の大きさとは無関係の px です。**文字を大きくしても縁は太くなりません
- **影のにじみは長さの半分**です。長くするほど広がり、そのぶん淡くなります。
  向きは「文字」→「影の向き」から 9 通り ―― 8 方向と、**ずれずに字のまわりへ広がる「真下」**
- 影の色は「文字」→「影の色...」、濃さは「影の濃さ...」で別々に指定します
  （色を選ぶパレットに濃さを置く場所が無いため）
- 入力中は縁取りと影を切り替えられません（入力欄はどちらも描かないため、変えても見た目が変わりません）
- 中身を全部消して確定すると、そのテキストは削除されます
- テキストツールを抜けると、IME は直接入力に戻ります

## 範囲を選ぶ

`W` で範囲選択（矩形をドラッグ）、`L` で投げ縄（手で囲う）です。投げ縄は離した時点で閉じます。**2 つは同じ範囲を共有します。**

| 操作 | 動作 |
|---|---|
| ドラッグ | 引き直す（前の範囲は消える） |
| `Shift` + ドラッグ | **足す**（離れた場所を同時に選べる） |
| `Alt` + ドラッグ | **引く**（穴を開ける）。引く範囲は赤い枠で出ます |
| クリック | 選択を解除 |

- 足す・引くは `Shift` と `Alt` です。`Ctrl` は使いません
- この 2 つのツールでは `Alt + ドラッグ` がスポイトになりません。`Shift + I` は使えます
- 範囲が消えるのは、引き直したときと、この 2 つ以外のツールに切り替えたときです
- 選択を変えた操作は `Ctrl+Z` で 1 つずつ戻せます。戻すと、そのときのツールにも切り替わります

## 色を置く・隠す

範囲を選んでから、右クリックメニューの「選択範囲」で選びます。

<img src="CCA2_RMB_Menu_06_area.png" width="200" alt="選択範囲のサブメニュー">

| 項目 | キー | 動作 |
|---|---|---|
| 塗りつぶし | `G` | 今の色で塗る |
| マーカー塗りつぶし | `Shift + G` | 同じ色を薄く塗る（下が透ける） |
| 境界線を描く | `O` | 範囲の縁に線を引く |
| マーカーで境界線を描く | `Shift + O` | 同じ線を薄く引く |
| モザイク | `M` | 範囲を隠す |
| ぼかし | `Shift + M` | 同上 |

- **キーは選択範囲があるときだけ働きます**
- `Shift` が付くほうが薄いほうです
- 塗りと線はペンの設定（色・線幅 `[` `]`・なめらかにする `A`）を使い、消しゴムで消せます
- 離れた場所を塗ると、場所ごとに別々に消せます（重なっている場所は 1 つ扱い）
- 選んだ形どおりに効きます。複数選択でも、穴を開けた形でも、投げ縄の形でも同じです

### モザイク・ぼかし

- 下に描いた線や文字も一緒に隠れます
- 隠れる中身はかけた時点の見た目です。後から下の線を消しても、隠れた中は変わりません
- かけた後に描いたものは、上に乗ります
- かけた直後は `[` `]` で強さを変えられます。`[` で 0 まで下げると消えます
- **選んだ範囲はかけた後も残ります。** モザイクをぼかしに変える、重ねる、が引き直さずにできます

## 画像を変える

右クリックメニューの「画像」から回転・反転・連結、「選択範囲」から切り抜きができます。

<img src="CCA2_RMB_Menu_07_image.png" width="240" alt="画像のサブメニュー">

| 項目 | 動作 |
|---|---|
| 左に / 右に 90 度回転、180 度回転 | 画質は落ちません |
| 自由に回転... | 角度を決めて回します。空いた角は黒で埋めます |
| 左右反転 / 上下反転 | |
| クリップボードの画像を右に / 下に連結 | 短い側は黒で埋めます |
| この範囲で切り抜く（選択範囲） | |

これらは描いたものを画像に焼き込みます。焼き込む前の状態は `Ctrl + Z` で戻せます。

### 自由に回転

スライダーか数値で角度を決めます（−360 〜 360 度）。

- 決めている間はウィンドウの絵がそのまま回ります（拡大率は変わりません）
- はみ出して見えなくなった部分も、確定すれば切れずに残ります
- 空いた角は黒で埋め、画像が大きくなった分ウィンドウも広がります
- 広がる向きは設定の「回転で動かさない所」で選べます（既定は中央、左上にすると右下へ伸びます）
- **任意の角度は少しぼやけます。繰り返すほど失われるので、一度で決めてください**（プレビュー中と、90 度・180 度の回転は劣化しません）

### 現在の状態でキャプチャ

メニューの「現在の状態でキャプチャ(更新)する」は、表示されているとおりを新しい画像にします。

- ズームした状態で使うと、実際に拡大された画像になります
- 描いたものは焼き込まれます

### 撮り直す

今のキャプチャを捨てて、範囲選択からやり直します。

## 拡大縮小で動かさない所

設定の「全般」で 3 通りから選べます（`ZoomAnchor`）。

| 値 | 動作 |
|---|---|
| `TopLeft` | 表示領域の左上を保ちます。ウィンドウは動きません（既定） |
| `Cursor` | カーソルの下にある点を保ちます |
| `Center` | 表示領域の中央を保ちます |

`Cursor` のとき:

- 回し続けている間は、最初に回した時点の位置を保ちます
- 0.4 秒ほど手を止めて別の場所で回すと、そこが新しい中心になります
- 中心を保つために画像がスクロールし、足りなければウィンドウが動きます（画面の外へはみ出すことがあります）
- `1`〜`5` とメニューの倍率指定にはカーソルがないので、画面の中央を保ちます

<img src="CCA2_RMB_Menu_08_view.png" width="200" alt="表示のサブメニュー">

## ウィンドウの枠

`WindowFrame` は 4 通りです。**次のキャプチャから反映されます。**

| 値 | 見た目 |
|---|---|
| `Normal` | タイトルバーと枠のある普通のウィンドウ |
| `ThinTitleBar` | 閉じるボタンだけの細いタイトルバー。タスクバーに出ません |
| `NoTitleBar` | 細い枠だけ（既定） |
| `NoFrame` | 枠もなし |

タイトルバーがないときは、ウィンドウの移動は中ボタンのドラッグです。

## しばらく隠す

- `X` を押すとウィンドウが完全に消え、`HideDurationMs`（既定 3 秒）で戻ります
- 押している間だけ隠す、という使い方はできません
- 戻るときはアクティブになりません

## 操作の割り当て

<img src="CCA2_Setting_07_hotkey.png" width="420" alt="設定の操作の割り当てタブ">

キーとマウスが 1 つの一覧に並びます。項目は 編集 / ファイル / ツール / 描く / 選択範囲 / 表示 / ウィンドウ に分かれています。

- 行を選んで「割り当てを変更」。キーの行はそのキーを押し、マウスの行は候補から選びます
- 「解除」で割り当てなしにできます
- **重複するとその行が赤くなり、直すまで OK を押せません**
- マウスの候補は、ドラッグ系（スクロール・ウィンドウ移動）とホイール系（ズーム・不透明度）で分かれています
- ズームを割り当てたジェスチャに `Shift` を足すと、1 段が小さくなります（既定なら `Ctrl + Shift + ホイール`）
- 割り当てにない修飾キーを押している間は、何も起きません
- スクロールの「左ドラッグ」は「ツールが左ボタンを使っていないとき」の意味です（ビューツールと Space 中）。スクロールを他へ移しても残ります
- 修飾キーなしの左ドラッグは、他の操作には割り当てられません

次のキーは変更できません。一覧には灰色の行として載っています。

| キー | 何に使うか |
|---|---|
| `[` `]` | 太さ・効果の強さ・指しているテキストの大きさを変える |
| `Shift + 1` 〜 `8` | クイックカラー |
| `1` 〜 `5` | 倍率を 100〜500% にする |
| 矢印キー | スクロール |
| Space + 左ドラッグ | 押している間だけスクロール |

次のものは一覧にも出ません。

- Shift + ドラッグ（直線）と、引いている最中の Shift（折り曲げ）
- 直線を引いている最中の Alt（角度を揃える）
- `Ctrl + B` / `I` / `U`（入力中の文字書式）

## 自動保存

`Folder` を設定すると、ウィンドウを閉じるときに自動で保存されます。

- サインアウト・シャットダウンで閉じられるときも保存します
- 手動で保存済みなら重複しません。「撮り直す」で捨てるときも保存しません
- **保存したくないときは、そのウィンドウを前面にして Shift を押しながら閉じます。** 前面のウィンドウにしか効きません
- 保存できなかったときは、その旨を知らせてウィンドウを閉じません。置き換え（開く・貼り付け）も中止します
- `HistoryDays` を過ぎたファイルはゴミ箱へ移動します（自動保存先の直下にある png / jpg / bmp だけ）

## 設定ファイル

設定は実行ファイルと同じ場所の `CapturaClipA2.ini` に保存されます。初回起動時に説明付きで作られるので、テキストエディタで直接編集しても構いません。読み込みは起動のたびです。

| 節 | 項目 | 内容 |
|---|---|---|
| Capture | `PreparationMs` | 画面を取り込むまでの待ち時間。メニューのフェードが残るときに増やす |
| | `CopyOnCapture` | キャプチャと同時にクリップボードへコピー |
| Text | `FontFamily` `FontSize` | テキストのフォントとサイズ |
| | `Shadow` `Outline` | テキストの影・縁取りをつけるか |
| | `OutlineWidth` `ShadowLength` | 縁の太さと影の長さ（px。文字の大きさとは無関係） |
| | `ShadowDirection` | 影の向き。`0` が上で時計回りに `7`、`8` は真下（にじみだけ） |
| | `ShadowColor` `ShadowOpacity` | 影の色と濃さ（%） |
| Drawing | `UsePenPressure` | 筆圧で線の太さを変えるか |
| | `PressureMinScale` | 最も弱い筆圧での太さの割合。`0.15` なら 15% |
| | `PenWidth` `PenColor` | ブラシの初期サイズと色 |
| | `EraserWidth` | 消しゴムの初期サイズ。ブラシとは別に覚えます |
| | `LineSnapDegrees` | 直線を引いている間に Alt を押したとき揃える角度。`0` で揃えません |
| | `ArrowScale` `ArrowAspect` `ArrowRounding` | 矢印の頭の幅・長さ・角の丸み。いずれも頭の幅が基準 |
| | `ArrowTurnDegrees` | `Ctrl + ↑` `Ctrl + ↓` 1 回で矢印を回す角度 |
| Colors | `Color1` 〜 `Color8` | Shift+1 〜 8 の色。パレット上段にも並びます。`#RRGGBB` |
| Appearance | `TitleFormat` | タイトルの書式。`%y %Y %m %d %h %n %s %t` が使える |
| | `SmoothScaling` | 拡大時の補間。`0` にするとドットがはっきり見える |
| | `ZoomStepPercent` | ホイール 1 段あたりの倍率変化 |
| | `ZoomAnchor` | 拡大縮小で動かさない所。`TopLeft` / `Cursor` / `Center` |
| | `RotateAnchor` | 自由に回転して画像が大きくなったとき動かさない所。`TopLeft` / `Center` |
| | `PaletteScalePercent` | カラーパレットの大きさ（50〜300）。高 DPI で調整用 |
| | `WindowFrame` | ウィンドウの枠 |
| | `HideDurationMs` | 「しばらく隠す」で消えている時間（ミリ秒） |
| Save | `DefaultFormat` | 保存形式の既定値（PNG / JPEG / BMP） |
| | `JpegQuality` | JPEG の画質（0〜100） |
| AutoSave | `Folder` | 自動保存先。空なら自動保存しない。`C:\Captures\%y-%m` のように書式が使える |
| | `HistoryDays` | 自動保存したファイルを残す日数。`0` なら消さない |
| Shortcuts | 各コマンド | `Ctrl+S` `B` `Shift+F1` のように書きます。空ならキーなし |
| Mouse | `Scroll` `MoveWindow` | `LeftDrag` `MiddleDrag` `RightDrag` `Ctrl+LeftDrag` `Ctrl+MiddleDrag` `Shift+MiddleDrag` |
| | `Zoom` `Opacity` | `Wheel` `Ctrl+Wheel` `Shift+Wheel` `Alt+Wheel` |

PNG に画質・圧縮率の設定はありません。
